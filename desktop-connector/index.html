Connect your Windows computer

YapThing Desktop Connector is a local, read-only pilot. It can report computer status and list files in your user folders. It cannot execute commands, edit files or connect to your PC over the internet.

Start the connector on the same Windows computer by running node yapthing-desktop-connector.js from the folder where you saved it. Copy the pairing token printed in the terminal. Do not share the token with anyone.

Not connected.

Privacy: The token is held in this tab only and is not sent to YapThing servers. Your browser contacts 127.0.0.1 on this computer. Stop the local connector to revoke access. Only approve trusted sites and never expose the connector port publicly.

If your browser blocks access to localhost, the connector may require browser local-network permission or a different secure transport. No connection is assumed until the status check succeeds.
