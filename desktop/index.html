Your computer. More YapThing.

Keep chat in its own app window, then connect your computer for reviewed file edits, code drafts and GitHub tasks—even from your phone.

1. Install the chat app

Open YapThing in Microsoft Edge or Chrome and install it as an app. It opens in its own window and uses the same account as the website. A Microsoft Store listing is not available yet.

2. Pair your computer

  1. Have Node.js and npm available, or choose the no-admin portable Node.js option below. A portable ZIP is placed under your Windows user folder without an MSI installation.
  2. Download and run the connector launcher below. It uses the official Desktop Commander agent. Follow the device-pairing page and keep the connector window open.
  3. Open YapThing chat → Tools → Set up or troubleshoot this computer. Connect your computer account, then choose Check connection.
  4. Choose Tools → New project, then select your connected computer and the project folder you want to work on. Use the same signed-in YapThing account on your phone to reach that computer. It must remain on and online.
Download standard launcher

No administrator access? The no-admin launcher uses an existing Node.js installation or, with your consent, downloads an official Node.js 24 LTS Windows ZIP, verifies its SHA-256 checksum against the official manifest, and extracts it under your user profile. It neither edits system PATH nor elevates permissions.

Download No-Admin Windows launcher

Inspect the downloaded .cmd file before running it. On a company-managed PC, use only software permitted by your organization. If downloads or application execution are blocked by policy, request approval or use YapThing chat without computer access.

For macOS or Linux, run npx @wonderwhy-er/desktop-commander@latest remote in Terminal.

Closing the connector stops new computer access. You can also disconnect the account from YapThing. Desktop Commander is a separate service with its own availability and terms.

3. Give YapThing a coding task

Selected paths, file contents, task previews and results pass through YapThing and Desktop Commander and are saved in your account’s Work history. Review the privacy details before choosing a project.

Ask in normal chat: “Fix this bug, run the tests, and prepare a draft pull request.” YapThing uses its existing Gemini connection to plan the work. After you approve the exact files and tests, it can inspect, edit, test and repair within that task. No local AI installation is required for this chat workflow.

Your existing chat and Work allowances apply. Reviewed actions show their credit cost before execution. PowerShell commands and publishing a draft pull request require separate approval. GitHub publishing uses GitHub CLI signed in on your computer. Keep the chat and connector window open while the task runs.

Coding tasks cover up to six approved files and supported project checks. YapThing can also read approved public web pages. Interactive control of a signed-in browser, automatic merges, deployments and live database execution are separate capabilities. The optional advanced local-model workflow remains available.
