✳ YapThing · Open your YapSpace

Your computer. More YapThing.

Keep chat in its own app window, then connect your computer for reviewed file edits, code drafts and GitHub tasks—even from your phone.

1. Install the chat app

Open YapThing in Microsoft Edge or Chrome and install it as an app. It opens in its own window and uses the same account as the website. A Microsoft Store listing is not available yet.

2. Pair your computer

  1. Install Node.js 20 or later if it is not already installed.
  2. Download and run the connector launcher below. It uses the official Desktop Commander agent. Follow the device-pairing page and keep the connector window open.
  3. Open YapThing chat → menu → Connections → Connect computer. Approve access using your own computer account, then return and choose Refresh connection.
  4. Choose Work → New project, then Find computers and choose a project folder. Use the same signed-in YapThing account on your phone to reach that computer. It must remain on and online.
Download Windows connector launcher

For macOS or Linux, run npx @wonderwhy-er/desktop-commander@latest remote in Terminal.

Closing the connector stops new computer access. You can also disconnect the account from YapThing. Desktop Commander is a separate service with its own availability and terms.

3. Code with your own tools

Selected paths, file contents, task previews and results pass through YapThing and Desktop Commander and are saved in your account’s Work history. Review the privacy details before choosing a project.

GitHub tasks use GitHub CLI: sign in on the computer with gh auth login. Code drafts use an installed local Ollama model. Nothing is applied or published until you approve a task preview.

Free reads and previews. Multi-file drafts settle to 1–5 Work credits based on local processing and output tokens, with 5 reserved while running. Saving a file uses 2; a project check 1; clone 2; draft PR 3. Completed paid actions use your shared monthly Work balance. Confirmed failures release reserved credits.

You can review drafts for up to six files in existing project folders, including SQL migrations. Live database queries, screen viewing, arbitrary mouse control and unattended agents are not included in this release.
