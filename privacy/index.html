Privacy Policy

YapThing · Updated October 30, 2026

YapThing is an Android AI assistant with chat, research, optional screenshot analysis, an optional user account, and basic work/project tools. This policy describes YapThing's app and website.

Data collected and stored

If you register, Supabase Auth handles your email address and account authentication. The Android app protects session credentials in app-private, Android Keystore-backed storage. The iPhone app keeps its refresh token in Keychain; native session tokens are not passed into page scripts.

When you use YapThing without signing in, local chats stay on that device. When you sign in, YapThing automatically synchronizes eligible text conversation history between your website, Android and iPhone sessions through Supabase account-owned database rows. That history may include private details you type into conversations. Chat text is transmitted over HTTPS and protected by per-account access controls, but is not end-to-end encrypted. Local attachments and photos are not included in cross-device chat-history sync. Work projects and other local data may have a separate optional account backup.

Selected local attachments, photographs, passwords, stored third-party access tokens, and private connected-app data are not included in these text backups. They may nevertheless be processed transiently when you explicitly request certain features.

External AI, images, and search

When you choose YapThing cloud chat, code drafting or cloud vision, your submitted prompt and applicable conversation context or selected image/file are sent through YapThing's backend to an external AI processor, Google's Gemini service, to provide the feature. On-device AI is processed locally when supported and selected. When you use search, your search query is sent to the selected public search provider. Search services may include Google-grounded search, Wikipedia, Crossref, GitHub or optional Brave Search. Google and Brave services depend on available server credentials and usage limits.

Optional location and clock

The live clock uses your device clock and timezone. Timezone alone does not establish your city. Location is off by default. You can type a city/timezone, explicitly choose approximate IP location, or request one device location fix with browser permission. IP lookup sends your public IP to ipapi.co, without chat text or account details. IP location can be inaccurate, especially with a VPN.

YapThing immediately rounds device coordinates to roughly a 1 km grid (coarser for inaccurate fixes), discards precise coordinates and raw IP data, and holds automatic city/area context in memory for up to 15 minutes. It does not save that context to your profile or track your movements. Manual city/timezone choices last until forgotten or the page/session ends. Local questions may send your selected city or rounded area to search/AI providers. Ordinary questions do not receive that context. Forget location, page exit, or account changes clear the context and invalidate pending lookups. Existing chat history can still mention a location; forgetting location does not delete chat history. Hosting, IP location, search and AI providers may process network logs under their own policies.

Connected computer Work

If you choose Computer & code, YapThing connects your own Desktop Commander account after its permission screen. Selected computer/project identifiers, file paths, prompts, selected file contents, approved edits and task results pass through YapThing’s backend and Desktop Commander. Task previews and results are stored with your YapThing account for Work history and credit accounting. This history is protected by account access controls and is not end-to-end encrypted.

Computer connection credentials and temporary connection verifiers are encrypted in server-side Vault storage. Disconnecting removes the stored computer connection credentials; existing task history remains until account deletion. Account deletion removes account-owned Work records. GitHub operations use GitHub CLI credentials on your computer. Local code drafting uses an installed Ollama model on that computer, while the selected context and result still travel through the connection described above.

Only choose folders and files you are comfortable processing through those services. Each computer action requires its own review and approval. Stopping a task does not undo file or GitHub changes already made.

Account controls

You can delete account-owned local data on your device, erase optional Work backups, sign out, or request permanent deletion of your YapThing account. Signing out immediately hides account conversations in YapThing's interface but may leave a locally cached, account-scoped copy on the device for when that same account signs in again. Account deletion removes the Supabase user record and associated account-owned profile, chat and backup records. Local data on offline devices or shared browser profiles may need to be cleared separately. Some security or legally required records may be retained if applicable.

Security and sharing

The app connects to backend services over HTTPS. We do not sell personal conversations to advertisers. Provider APIs process only the information necessary for the specific feature you choose. Gmail inbox and private GitHub, Slack, Drive and Microsoft services are not automatically connected by signing in to YapThing.

Topic-aware research

When you ask a research question, YapThing may combine Google Search grounding with public literature and topic indexes, including Europe PMC/PubMed, Crossref and GitHub. Automatic Google topic research sends generalized health topic terms to Google and Europe PMC rather than your personal narrative. Other explicitly selected search providers, medical education and normal chat services may process the original question as described for those features. Other research requests may send the current search terms to the relevant provider. These providers process requests under their own policies. Topic routing runs per request; it does not create a health profile or monitor you in the background. Your messages can still be saved in chat history and processed by the normal chat service according to the features you use. Retrieved abstracts and search results can be incomplete, outdated or unrelated. Health answers are educational information, not diagnosis, treatment or emergency care.

Website

The website frontend is hosted through GitHub Pages. Website sign-in and account creation use YapThing backend services. Signed-in text conversations are synchronized with Supabase; the browser also stores a local cache scoped to the signed-in account. Signed-out chats start in a fresh in-memory session and do not display a previous account's local history. Older unscoped browser chats are imported only after an explicit owner confirmation. The installable website may cache app files and session data. GitHub may process standard network request logs under its own policies.

Contact and requests

For privacy questions or a deletion request, email support@yapthing.com or use the account deletion instructions.
