Privacy Policy

YapThing · Updated October 30, 2026

YapThing is an Android AI assistant with chat, research, optional screenshot analysis, an optional user account, and basic work/project tools. This policy describes YapThing's app and website.

Data collected and stored

If you register, Supabase Auth handles your email address and account authentication. The Android app protects session credentials in app-private, Android Keystore-backed storage. The iPhone app keeps its refresh token in Keychain; native session tokens are not passed into page scripts.

By default, YapThing text chats, saved memories and YapWork projects are saved locally on your device. If you explicitly choose cloud backup, the app uploads a selected text snapshot to a Supabase account-owned database row. The backup may include sensitive text you typed into chats or project descriptions. Cloud backups are protected by account access controls but are not end-to-end encrypted.

Selected local attachments, photographs, passwords, stored third-party access tokens, and private connected-app data are not included in these text backups. They may nevertheless be processed transiently when you explicitly request certain features.

External AI, images, and search

If you elect to use cloud vision for a photo or screenshot, the selected image and prompt are sent to YapThing's backend and Google's Gemini service for analysis. When you use search, your search query is sent to the selected public search provider. Search services may include Google-grounded search, Wikipedia, Crossref, GitHub or optional Brave Search. Google and Brave services depend on available server credentials and usage limits.

Connected computer Work

If you choose Computer & code, YapThing connects your own Desktop Commander account after its permission screen. Selected computer/project identifiers, file paths, prompts, selected file contents, approved edits and task results pass through YapThing’s backend and Desktop Commander. Task previews and results are stored with your YapThing account for Work history and credit accounting. This history is protected by account access controls and is not end-to-end encrypted.

Computer connection credentials and temporary connection verifiers are encrypted in server-side Vault storage. Disconnecting removes the stored computer connection credentials; existing task history remains until account deletion. Account deletion removes account-owned Work records. GitHub operations use GitHub CLI credentials on your computer. Local code drafting uses an installed Ollama model on that computer, while the selected context and result still travel through the connection described above.

Only choose folders and files you are comfortable processing through those services. Each computer action requires its own review and approval. Stopping a task does not undo file or GitHub changes already made.

Account controls

You can disable automatic backup, delete your cloud backup, sign out, or request permanent deletion of your YapThing account. Account deletion removes the Supabase user record and associated account-owned profile/backup data. Local data on offline devices may need to be cleared separately. Some security or legally required records may be retained if applicable.

Security and sharing

The app connects to backend services over HTTPS. We do not sell personal conversations to advertisers. Provider APIs process only the information necessary for the specific feature you choose. Gmail inbox and private GitHub, Slack, Drive and Microsoft services are not automatically connected by signing in to YapThing.

Website

The website frontend is hosted through GitHub Pages. Website sign-in, account creation and optional connected features use YapThing backend services. The installable website uses browser storage for its session, local chat history and cached app files. The same feature-specific data handling described above applies. GitHub may process standard network request logs under its own policies.

Contact and requests

For privacy questions or a deletion request, email support@yapthing.com or use the account deletion instructions.
