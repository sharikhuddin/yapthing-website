SEARCH DISCOVERY

Search engines & answer engines

The public sitemap now includes product pages, guides, desktop setup and account deletion guidance. Website checks below inspect those pages automatically.

  • Google: verify the domain in Search Console, submit https://yapthing.com/sitemap.xml, and inspect important URLs. Account verification and indexing are not confirmed by this dashboard.
  • Bing and participating IndexNow engines: a repository workflow sends changed public page URLs after a successful Pages deployment and matching live content checks. Open the workflow receipt to see whether a notification was received or failed. Receipt is not indexing.
  • AI search: public crawling remains allowed. AI citations and search impressions require real external measurements; technical checks cannot establish visibility.

Search check runs & notification receipts · Google Search Console · Bing Webmaster Tools · Sitemap · Public guides

Before saving a public-page edit, run node scripts/search-build.cjs. It keeps metadata, structured data, navigation, content hashes and meaningful sitemap modification dates in sync.
